# 官方参考资料

本教程主要依据以下官方项目与文档编写：

- Kubernetes Documentation：Pods、Deployments、Services、ConfigMaps、Secrets、Storage、Probes、Autoscaling、Ingress、RBAC、Jobs、StatefulSets、DaemonSets、NetworkPolicies
- Minikube Documentation：Start、Docker driver、Addons、Dashboard、Headlamp、Ingress、Metrics Server、多节点集群
- Kubernetes Dashboard / Headlamp 迁移说明

为避免文档中的外部链接随版本变化失效，教程正文主要使用稳定概念和本项目内链。遇到命令与当前版本不一致时，优先执行 `kubectl explain`、`minikube addons list` 并查阅对应版本的官方文档。
